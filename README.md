# 🛍️ StyleCart – E-Commerce Website

StyleCart is a modern **E-Commerce Website** designed to provide users with a simple and user-friendly online shopping experience. The project includes product browsing, user registration and login pages, shopping cart functionality, and supporting pages such as About and Contact.

## 🌐 Project Overview

The main objective of StyleCart is to build a responsive and visually appealing online shopping platform using front-end web technologies.

The website provides a structured shopping experience where users can explore products, manage their shopping cart, and navigate through different sections of the website.

## ✨ Features

* 🏠 **Home Page** – Attractive landing page for the online store
* 🛍️ **Products Page** – Displays available products
* 🛒 **Shopping Cart** – Allows users to manage selected products
* 🔐 **Login Page** – User login interface
* 📝 **Registration Page** – New user registration interface
* 🔑 **Forgot Password** – Password recovery interface
* 📖 **About Page** – Information about StyleCart
* 📞 **Contact Page** – Contact and communication section
* 🖼️ **Product Images** – Organized image assets for the website
* 📱 **User-Friendly Interface** – Simple and easy-to-navigate design

## 🛠️ Technologies Used

* **HTML5** – Website structure and page development
* **CSS3** – Styling, layout, and visual design
* **JavaScript** – Client-side interactions and functionality

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ramenavamsikowsik-cyber/Stylecart-e-commerce-website.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd Stylecart-e-commerce-website
```

### 3. Run the Website

Since this is a front-end project, you can open:

```text
homepage.html
```

directly in your web browser.

For a better development experience, you can also run the project using a local development server such as **VS Code Live Server**.
